# Nunito Sans Optimized Font Kit

A lightweight, optimized version of Nunito Sans specifically tuned for medical and corporate web interfaces. This kit includes only the essential weights and Cyrillic subsets to ensure maximum performance and clean typography.

## Key Benefits

| Feature | Description |
| :--- | :--- |
| **Performance** | Includes only `.woff2` formats and necessary character sets for minimal file size. |
| **Readability** | Strikes a perfect balance between friendliness and professional strictness. |
| **Numerals** | Clear and confident display of numbers, crucial for prices, dosages, and data tables. |
| **Cyrillic Support** | Full Russian language support without unnecessary extra symbols or bloat. |

## Installation

1. Download the `.woff2` files from the `fonts/` directory.
2. Copy the CSS rules from `style.css` into your project's stylesheet.
3. Ensure the `src` paths in the CSS match your local folder structure.
